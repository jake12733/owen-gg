# Owen.gg - 롤 전적 검색 사이트

## 실행
1. Node.js 18 이상 설치
2. `start.bat` 더블클릭 (또는 `node server.js`) 후 http://localhost:3000 접속
3. 우측 상단 톱니바퀴 > Riot API 키 입력 (https://developer.riotgames.com 에서 발급, 개발 키는 24시간마다 만료)

키를 config.json 에 넣어도 됩니다: `{ "riotApiKey": "RGAPI-..." }`
키가 없으면 데모 데이터로 모든 화면을 체험할 수 있습니다.

## 기능
- Riot ID(이름#태그) 검색, 14개 서버
- 솔로/자유랭크 티어, LP, 승률
- 최근 매치 (큐 필터, 더 보기), MVP/ACE, OP 스코어, 멀티킬
- 매치 상세: 종합 / 팀 분석 / 내 빌드
- 최근 게임 요약, 챔피언 통계, 선호 포지션, 함께 플레이한 소환사, 숙련도
- 인게임(관전) 정보, 챌린저/그마/마스터 랭킹, 이번 주 무료 챔피언
- 최근 검색, 즐겨찾기
